## 3. The plan — printed always, before anything

### 3a. The freshness gate — before `--run`, every time

**What reaches testers matches a known commit at the trunk's tip** (HA#146: a 95-commit-stale
archive was one green `--run` from TestFlight). After the plan:

```sh
"$hatsu_root/scripts/send_freshness_check.sh" --repo <path>   # [--base <branch>]; default branch.base
```

**Exit `0`** — `fresh` — prints § 5's four lines; § 4 sends from here. **Exit `3`** (no
`tags.identity`): tree clean, § 4 sends from here, § 5 reads `unverified`. **Exit `2`** naming a dirty tree, no archive, a build SHA **not `HEAD`** or **not
`origin/<base>`'s tip** (both SHAs named) is **row `stale-send`: § 3b rebuilds,
never a send from here, never a question**; exit `2` on a malformed `nameFrom` (a symlink,
out-of-tree, a bad SHA) is a declaration defect — **stop**.

### 3b. The fresh build — susanoo, in a clean worktree at the trunk's tip, ONLY when owed

**Ruling 2026-09-29 (HA#146)**: *"kagutsuchi by default runs susanoo for a fresh build ONLY when
latest build is not up to date with target branch"* — in one idempotent worktree, the maintainer's
own files copied from core (the two rulings before it).

Core is `nen wc worktrees --repo <path> --json`'s `core`; an active `nen wc swap` **refuses**
([`amenotejikara`](../amenotejikara/SKILL.md)). Then, plan first:

```sh
"$hatsu_root/scripts/kagutsuchi_worktree.sh" --repo <path> [--base <branch.base>] [--dry-run]
```

**Its header is the contract**: fetch; **one** detached worktree at `<core>/.nen/worktrees/kagutsuchi`
at `origin/<base>` — `created` | `reused` (**idempotent**) | `moved`; **dirty → exit `2`, never
discarded**; every `project.fromCore` path copied **from core only**, proven untracked, gitignored
and regular **in core and at the tip**, nothing synthesised; `copied:` and `core-ignore:` lines. Then [`susanoo`](../susanoo/SKILL.md) `--repo <worktree>` (`## 0.` skipped,

## 4. The send — only on the call, only that target

```bash
nen shu deploy --repo <path> [--lane <lane>] --target <name> --run
```

`--run` is a second, independent flag — **no single-flag path to acting**. Run it **once**; on a
failure read § 5, fix the named fact and re-run under the same call.

### 4a. The distribution tag — OPT-IN, and only after the send succeeded

A repository may ask for what was sent to be tagged by declaring `tags.identity.nameFrom` (the identity, then the build SHA; [`susanoo`](../susanoo/SKILL.md)
§ 5a) and `tags.deploy.<target>` (whether, and whether pushed). **Every check and the cut live in
[`scripts/dist_tag.sh`](../../../scripts/dist_tag.sh)** — its header is the contract — run **only
after a green `--run`**, the target in a file ([PROCESS.md](../../../docs/PROCESS.md) § *Escaping the
maintainer's words*):

```sh
"$hatsu_root/scripts/dist_tag.sh" --repo <path> --target-file "$target_file" [--dry-run]
```

**Exit `0`** cut; **`3`** not declared; **`2`** refused; **`1`** `nen tag cut` refused — **its reason
stands**. A rejected `--push`: delete the local tag, **verified absent from `origin`**,
re-cut. **A tag refusal never unsends anything.**

## 5. The refusals, credentials, and the report

Codes per `claude/agents/kurapika.md` § *The `shu` verbs*; **a seat beats a typo**.

| Exit | Fact | Reaction |
|---|---|---|
| `1` | the deploy tool ran and **failed** | relay its output and **the destination's state — or that you do not know it** |
| `2` | `--target` naming no declared destination | **refused** (§ 1), the declaration PR named, the keys shown — **never a near-match** |
| `2` | `--run` with `--dry-run`; an unsatisfied precondition or `requiresEnv` variable | fix the wiring; the plan **still prints, the failing rows `FAIL`** |
| `3` | **unsupported host** | **G5.** Name the hosts the declaration allows and stop — never retry |
| `4` | **a seat**, or the target declares `unsupported` | quote it verbatim and stop |
| `5` | the program could not be started | `nen shu tools --repo <path>`; relay the remedy |

**Credentials are asserted, never handled**: nen checks each `requiresEnv` **variable** is set without
reading it; this skill never reads, prints or asks for one. An unset one is exit `2` with
its **name**.
