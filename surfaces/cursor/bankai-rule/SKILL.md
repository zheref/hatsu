# Bankai rule — a port ruling, recorded once, cited forever

**Nature: Conjurer** — the ruling is canon (`CON-7`, `CON-13`), authored only on the maintainer's

## 3. Reserve the id — against the tip and every open PR


**Each row carries, in this order:**

| Column | What |

## 5. `port-drift` — one picker call per run, three questions a call

given**, before any PR exists, and becomes one row through §§ 3–4 on the run's rulings branch.

## Authority

## Hard limits

- **Never writes a row without the maintainer's answer** — the picker's, or the typed `ruling`
  text, stated back first.
- **Never parses the ruling text through the grammar**: the head is parsed, the ruling is split off
  at its first `ruling` (§ 1's probe).
- **Never names a scenario the matrix does not list**, never ports to or from an ungoverned one.
- **Never edits a merged row**: a reversal is a new row with `supersedes`.
- **Never reuses or renumbers an id across efforts**: a collision is renumbered only in this run's
  own branch, before its merge.
- **Never opens the rulings PR before the port run ends, never as a draft, never twice.**
- **Never merges** (`CON-7`): the maintainer's prompt is `en` § 5's.
