## 2 · Auto-install — host first, session as fallback

Absent or unsatisfied is an install, not a halt. **The host is the DEFAULT** (ROSTER ruling A,
2026-09-30; the SessionStart hook's step 0): **the hook acts, § 2c verifies.** `nen_global.sh`'s

```bash

```

| Exit | Then |
|---|---|
| `0` `current` · `linked` · `kept-newer` | re-probe via `command -v nen`; `PATH` missing the link → `export PATH="$HOME/.local/bin:$PATH"` **in the block**; **§ 2c**, summary line quoted |

| `2` usage, contract unreadable, URL off `<source>/<pinned_ref>` | fix, rerun **once**; else as `skipped` |
| `5` bootstrap or verification failed | **§ 3** |

**The session bind** — a private `mktemp -d` (`0700`), **never a predictable `/tmp` path**:

```bash
d="$(mktemp -d)"; curl -fsSL <dependency.bootstrap.url> -o "$d/nen-bootstrap.sh"
out="$(bash "$d/nen-bootstrap.sh" --ref <pinned_ref>)" || <§ 3, rc quoted>  # the shell line, nen ABSENT; or
out="$(nen bootstrap --ref <pinned_ref> --source <source> --script "$d/nen-bootstrap.sh")" || <§ 3, rc quoted>  # the verb line, nen present

```

- ⚠️ **Fetch to a file; never pipe the script into bash** (piped, it **exits `1`, a code in no
  table**); **the shell line only with nen absent**, **the verb line's `--script` required**; **no

- **Never copy or rename the binary.** **Publishing `nen` itself → the verb line for its tag**
