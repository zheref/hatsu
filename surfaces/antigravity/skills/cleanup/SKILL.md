## 5. The plan — two classes, every row complete

**Deterministic** (a mechanical fact decides; pre-selected): `git worktree prune`; `git worktree remove
<wt>` for a Hatsu-made worktree whose PR is **merged** and whose tree is **`on-branch-clean`**, then
`git branch -d <branch>` (it refuses an unmerged branch itself); `hanten-<persona>` and `prove-<n>` when
clean; `git push origin --delete <branch>` for a merged PR's head origin still has (the base-branch guard
refuses the trunk and every force form; never a branch with an open PR); `git remote prune origin`;
`rm <reports.dir>/current.html`; a bootstrap-cache binary below the pin that **no link points to**.

**Proposed** (a judgement; unselected; the row names what it destroys and why it is uncertain): a
worktree with uncommitted work (every path listed — never discarded unseen); a branch whose PR is
**closed unmerged**, or that has **no PR**; `captures/` of a merged effort; a build cache inside a kept
worktree; an Actions cache or artifact; a draft release; a runner host (an on-device act — the plan
names it, the maintainer performs it); the surface's own worktrees.

Each row: `id` · class · object · the exact command · what it frees (bytes, or `billed: <what>`) ·
evidence (PR state, dirt, age) · owner (this sitting, or `prior: <branch>`).

## 6. The picker — then only the pick runs

One multi-select question through the surface's own picker (third-hand § 6's table; row
`cleanup-plan`): every row as an option, deterministic ones pre-selected, proposed ones not, plus
**`none` — keep everything**. **Nothing is removed before the answer**, and `none` wins over every other
tick. Pass 2 runs the picked rows in order — local first, the remote delete last — each followed by its
read-back (`git worktree list`, `git branch`, `git ls-remote --heads origin`, `du -sk`), and reports one
line per row with the bytes freed, then the total. A row that fails is reported with its stderr and
**never retried with a wider flag**.
