### Added

- **The ten-PR shrink line of the prose ratchet (zheref/hatsu#448, AC-4's second half).** `scripts/prose_ambiguity_check.mts --history <n>` (1 to 100) lints nothing and reads git alone. It walks `HEAD`'s first-parent line and keeps the last `<n>` pull requests whose diff touches a canon prose path. A pull request is a `Merge pull request #N` merge or a squash commit whose subject ends `(#N)`; an integration branch's sub-PRs count once, through their delivery PR. For each one it counts the removed baseline rows against its first parent's baseline, exactly as `--base-baseline` counts them, and prints one line per pull request, their sum and the baseline's findings at `HEAD` (SC-2's figure). A prose commit naming no pull request (a rebase merge, a direct commit) and a non-PR merge are counted as skipped (`skippedNonMergeProse`, `skippedNonPrMergeProse`), never as pull requests. A pull request whose tree has no baseline is flagged `baselineAbsent` and left out of the sum. The walk's end is said: `complete`, `ratchet-start`, `history-start` or `scan-cap` (`HATSU_PROSE_HISTORY_SCAN`, default 5000). A shallow clone, a `HEAD` with no baseline, `--base`, `--base-baseline` or `--self-test` beside it, or a bad count is wiring (exit `2`). `--json` prints `hatsu.prose-lint.history/v0.1`. `--self-test` now refuses any other flag. Changed paths, here and in `--base`'s scope, are read NUL-split with `core.quotePath=false`, so a non-ASCII path reads as itself. The `canon-lint` fixture builds merge histories for each case.
- **The morning desk quotes it.** `contracts/schedule.json`'s `morning-desk` prompt runs `node scripts/prose_ambiguity_check.mts --root . --history 10` and quotes its last line beside the register's link, stating the counting rule; a non-zero exit is reported as not run. That exact command, never a prefix, joins the row's `alwaysAllow`. `docs/config/schedule.md` § *Permissions* says it is safe only because the desk runs at `origin/main`'s commit; § *Row 4* replaces the *owed* line with the verb, and the table row names the quote. `docs/ab/schedule-install.md` re-records the printout on this branch over `main` `00881fc1d` and records the first live `--history 10`. The CI workflow is unchanged: its guard step is frozen and its per-PR count stays. AC-2's tag trigger stays owed, as the page says.
