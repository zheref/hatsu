### Changed

- **Every report now has a Markdown template beside its HTML one, filled by `nen report render` from the same data document** ([#215](https://github.com/zheref/hatsu/issues/215); its predecessor [#145](https://github.com/zheref/hatsu/issues/145) fixed where the artifact goes). `templates/spiritual-message.md` covers `turn`, `turn-fast` and `landing`; `templates/rikugan.md` covers `final` and `register`. Each mirrors its HTML template block for block, from the same `reports.sections.<variant>.blocks`: one starred option per ask, the `nen pr ready` verdict quoted, the G5 evidence in `g5-blocker`, the delta as a `mermaid` fence, and commands and multi-line values in `<pre>`. On Antigravity the artifact is no longer composed from a description, so its structure no longer drifts from turn to turn. It is rendered to `<reports.dir>/current.md` with `--graph` always passed (nen's `--out` stays inside `--repo`), copied verbatim into `write_to_file`, and read back with `cmp`; one rewrite is allowed, and a second difference yields the turn unpublished. `docs/PROCESS.md` § *The Markdown report* states the surface-neutral rule, the one step no verb performs, the checked example per variant, and a caller-side interim: no newline in a value outside a `<pre>` slot. § *Escaping and validation of report data* now says plainly that nen escapes HTML only, so every value in the Markdown twins is live Markdown outside `<pre>` and fences. Link and image syntax in third-party titles is a named gap, and `graphMermaid` is a raw slot that is safe only on the `--graph` path. `spiritual-message` § 7, `rikugan` §§ 4–5, `backlog-board` § 3 and rules item 9 point at the section; `docs/surfaces/antigravity.md` records the three steps and their provenance. A new `report-markdown-guard` lane renders every variant in both formats from `templates/report-examples/` (36 fixture cases). It holds block order, starred option lines, escaping placement (spans, fences, indented code), token parity both ways, no data-carried `graphMermaid`, no stray newline, and the checked examples. **Owed to nen** (§ *Residue and owned dependencies*, not yet filed): render-time Markdown escaping, and a render to stdout or outside `--repo`. **On the desk, G4:** `scripts/report_markdown_check.sh` is embedded Python that BC-11 reads as owed to a nen verb (ROSTER § *Rulings of 2026-10-03*); port it or waive it. Until then it takes fixes only. Plugin bumped to 0.103.0; mirrors regenerated at that stamp.
