A port ruling — what a source stack's rule or concept becomes on the target: `mirror` · `map` · `drop with note` · `target-only addition` — recorded once as a stable-id row in a directed pair file of `zheref/bankai-handbooks`' `handbooks/ports/` family (rendered from `templates/ports/`), the id reserved against the tip and every open PR (`scripts/port_rule_reserve.sh`, the `port-rule-guard` lane's two-branch fixture), one rulings PR per port run through `aka → mukai → en` to the G4 prompt.
