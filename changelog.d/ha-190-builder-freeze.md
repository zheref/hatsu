### Changed

- **Every step of `surface-mirror-regenerate.yml` except its pull-request step is admitted only in its exact form** ([#190](https://github.com/zheref/hatsu/issues/190)). The job holds `contents: write`, and its only push guard was lexical: `git -C . push origin HEAD:refs/tags/v9.9.9`, or a `gh api -X DELETE` of another branch, added to any run step passed `main`'s validator. `REGENERATE_FROZEN_STEPS` now holds each step's keys, `env`, `if`, `id`, `shell`, the checkout's `with` and the run byte for byte, comment lines included. The pull-request step is held short of that (`REGENERATE_PR_WITH`): its exact keys and `with` inputs, and every input's value but `body`'s free prose; no `with` value reaches a shell. **A `${{ }}` expression in any workflow's run is refused**, comment lines included, because Actions substitutes it into the shell source; that covers `github.event.*` and every other context. Sixteen new refused cases, none caught by an earlier check, and one showing `body` stays free. A change to a builder step's body is now a two-step landing (`docs/GATE-CONFIGURATION.md`, `docs/using/mirrors.md` § 4). **This delivers part of #190: its `v*` tag ruleset is a repository setting, the maintainer's step, on the desk as a DO ask;** `docs/GATE-CONFIGURATION.md` carries the ruleset's body and the `PUT` shape for changing one. Plugin bumped to 0.104.0 (shipped docs); mirrors restamped.
