### Changed

- **Every step of `surface-mirror-regenerate.yml` except its pull-request step is admitted only in its exact form** ([#190](https://github.com/zheref/hatsu/issues/190)). The job holds `contents: write`, and its only push guard was lexical: `git -C . push origin HEAD:refs/tags/v9.9.9`, or a `gh api -X DELETE` of another branch, added to any run step passed `main`'s validator. `REGENERATE_FROZEN_STEPS` now holds each step's keys, `env`, `if`, `id`, `shell`, the checkout's `with` and the run byte for byte, comment lines included. **A `${{ }}` expression in any workflow's run is refused**, comment lines included, because Actions substitutes it into the shell source; that covers `github.event.*` and every other context. Thirteen new fixtures, none caught by an earlier check. A change to a builder step's body is now a two-step landing (`docs/GATE-CONFIGURATION.md`, `docs/using/mirrors.md` § 4). Protecting `v*` release tags is a repository ruleset the maintainer applies. Plugin bumped to 0.104.0 (shipped docs); mirrors restamped.
