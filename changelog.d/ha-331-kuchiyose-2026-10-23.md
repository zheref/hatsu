### Added

- **`hatsu:kuchiyose`, the CI tier installer (zheref/hatsu#331; HR-135 … HR-142).** On a repository `tenkai` has adopted, `hatsu:kuchiyose [tier <tier>] [--repo <path>] [--dry-run]` resolves the Akatsuki provider by its code `AK` and its pinned release tag, reads the tier catalogue at that tag, asks the tier and the per-consumer rulings in one picker call (Hidan on or off; Claude billing with the subscription token starred), and lands the caller workflow, the lanes' `nen/gates.json` entries (`wake: "event"`, never `base_reviewers`) and the `nen/workflow.json` → `ci` block as one PR at the consumer's own gate, plus the provider's registry row as a second PR. The day-one ceremony (the `-akatsuki` Apps, their secrets, the Claude secret, the Hidan variable, the required-checks ruleset) is printed one block per step and never performed; `hatsu:kuchiyose verify` reads each lane's state off `nen pr ready --json`, never a check's colour. `nen/decisions.json` gains two human-gate rows (`ci-install-rulings`, `ci-ceremony`); `contracts/config-catalogue.json` gains the `ci` domain and five rows, none defaulted, each `ownedBy: kuchiyose` so `config_values.sh diagnose`, `fill` and `need` never list them and `tenkai` never asks or fills them (`scripts/config_values_owned_fixture.ts`); `contracts/permissions.json` denies the session `gh secret set`/`delete`, `gh variable set` and `gh api` writes to rulesets, secrets and variables; PROCESS and GATE-CONFIGURATION are repinned to nen `0.26`'s `wake: "event"`; `scripts/provider_tag_commit.mts` peels a provider release tag to its commit (an annotated tag's object is never compared with a commit), fixture-held in lane `gh-api-read-guard`; PROCESS's pre-0.26 *until zheref/nen#372* sentence is replaced by the base-read rule; the guide is `docs/using/kuchiyose.md` and the dry run `docs/ab/kuchiyose.md`. The skill joins the dieted list and its three surface mirrors. **Today it stops before writing on every consumer**: the provider has no release tag, no `schemas/tiers.json` and no caller render verb yet (zheref/akatsuki-ai#49, #50), and nen `0.26`'s `nen schema set` cannot add a member to a gates array, so the gates write names that gap rather than hand-editing the file.
