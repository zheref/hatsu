### Changed

- **`surface-mirror-check.yml`, `pr-readiness.yml` and `surface-mirror-regenerate.yml` hash the binary the bootstrap printed and compare it with the trusted checkout's `dependency.bootstrap.sha256["linux-x64"]`** ([#230](https://github.com/zheref/hatsu/issues/230)). Each fails closed on a mismatch or a missing or malformed key, naming expected and observed. The bootstrap script verifies the binary against `SHA256SUMS` from the same release, so a moved tag or replaced assets verified against themselves. The change landed in two steps: the validator learned the step first, then the live workflows took it and Hatsu's own forms were narrowed to carrying it, frozen (`NEN_DIGEST_FROZEN`). The live step passes the published v0.21.0 linux-x64 binary and fails a one-byte tamper. **A repin moves the linux-x64 digest with `pinned_ref`, in the same pull request,** or every pull request after it fails closed. Tenkai's rendered readiness form carries no digest step yet, and the optional bootstrap-script digest is not recorded (a follow-up). Plugin bumped to 0.105.0; mirrors restamped.
