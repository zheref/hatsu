### Changed

- **The generated mirrors no longer carry the plugin version, so a bump rewrites one mirror file instead of 252 (zheref/hatsu#530).** `scripts/surface_mirror_regenerate.sh` and `scripts/surface_mirror_check.sh` stop passing `--stamp` to `nen surface mirror generate` and `check`, so every marker now reads `<!-- GENERATED by nen surface mirror (surface: codex) -->` with no version in it. The version still reaches `surfaces/antigravity/plugin.json`, through `--manifest`, because that one generated file **is** a plugin manifest declaring a version rather than a copy of one; it is the single mirror a bump still touches. Measured before the change: 26 of the 60 most recent commits touching `surfaces/` (43%) changed nothing but the version, and of the last 20, nine rewrote all 252 files while five of those nine carried no content change at all. 🔀 HA-PR-#526 — a hook module for Claude Code, the one surface no mirror serves — changed 276 files, 761 of its 811 file diffs marker-only, with exactly one mirror changed for any other reason. Nothing read that version except the guard scan retired below: `scripts/surface_bootstrap.sh` and `hooks/session-start.sh` match the marker's **surface name** and stop before the version, and a mirror's correctness has always been `nen surface mirror check`'s byte comparison, which the stamp could only make stricter in the wrong direction — a skill whose body had not moved for fifty versions was byte-identical to a fresh generation but for its marker, and the check called that copy stale.
- **Both marker grammars are read, so a copy placed before this change still works.** A mirror placed into a consumer's workspace carries `(surface: <s>, stamp: <version>)` until its next refresh. `hooks/session-start.sh` cuts the surface name at whichever of `,` or `)` comes first and matches both forms as fixed strings (never a regex, so `$surface` never reaches a pattern); `scripts/surface_bootstrap.sh`'s `is_ours_hooks`, `has_marker_under` and `is_ours_codex_only` each accept both. `scripts/nen_global_fixture_check.sh` case 31b is the proof: a copy carrying the pre-#530 stamped marker still resolves its surface and still refreshes. A reader that stopped accepting the old form would stop refreshing those copies silently, which is the one failure this mechanism exists to prevent.
- **`docs/using/mirrors.md` § 1 reverses its own rule.** "A stamp behind `.claude-plugin/plugin.json` is drift even when the bytes match" is gone; a mirror whose bytes match a fresh generation is current, whatever the manifest beside it declares. `docs/surfaces/README.md`, `codex.md`, `cursor.md` and `antigravity.md` carry the new marker, `great-hiker` § 4 names `--manifest` in `--stamp`'s place, and `bakuryuha`, `getsuga`, `tenkai` and Phinks's brief drop their stamp references.

### Removed

- **`surfaces_stamp_scan` from `scripts/plugin_bump_check.sh`.** It existed only to name the bump as the cause of the drift the bump itself created (zheref/hatsu#99, which deliberately took no position on decoupling and routed it to a separate issue — this one, which also corrects that routing: `--stamp` is optional in the pinned generator, so no companion change was needed in it). With the stamp gone there is no lag to explain, and with the scan gone so is its whole attack surface: the PR-head-controlled marker text it had to sanitise against a forged workflow command, a CR, a malformed version and a symlinked surface directory. The guard's Codex-overlay read is untouched — `.codex-plugin/plugin.json`'s version is a real cache key and still must track the Claude manifest's. `scripts/plugin_bump_check_fixture.sh` replaces the eleven stamp-lag rows with two: the exact tree that used to fail by name now passes, and a bumped manifest beside mirrors carrying no version passes, each asserting the retired scan says nothing at all. `scripts/surface_mirror_regenerate_fixture.sh` § 6 runs the real pinned generator on a scratch checkout and asserts the count: a manifest-only version change rewrites exactly 1 mirror file, `surfaces/antigravity/plugin.json`, version line only, and no generated file carries a `stamp:` marker. Plugin 0.156.0, mirrors regenerated.
