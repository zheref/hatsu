### Changed

- **The generated mirrors no longer carry the plugin version, so a bump rewrites one mirror file instead of 252 (zheref/hatsu#530).** `scripts/surface_mirror_regenerate.sh` and `scripts/surface_mirror_check.sh` stop passing `--stamp` to `nen surface mirror generate` and `check`, so every marker now reads `<!-- GENERATED by nen surface mirror (surface: codex) -->` with no version in it. The version still reaches `surfaces/antigravity/plugin.json`, through `--manifest`, because that one generated file **is** a plugin manifest declaring a version rather than a copy of one; it is the single mirror a bump still touches. Measured before the change, measured with first-parent `git diff --unified=0 <c>^1 <c> -- surfaces/`, a file diff counted marker-only when every changed line matches the marker or a `"version"` key: over the 60 most recent commits touching `surfaces/`, 6,284 of the 7,201 file diffs there (87.3%) changed nothing but the marker; nine of the last 20 such commits rewrote all 252 files, carrying 0 to 16 files of real change (median 4) between them. 🔀 HA-PR-#526 — a hook module for Claude Code, the one surface no mirror serves — carries 276 changed files at head `84b341fb`, of which 252 are mirrors and 251 of those are a single changed line; 24 files carry the actual change (`gh api repos/zheref/hatsu/pulls/526/files`, read 2026-10-29). An earlier draft of this fragment and of `docs/using/mirrors.md` stated "43% of commits" and "761 of 811 file diffs": the first counted merge commits whose first-parent `surfaces/` diff is empty as marker-only, and the second summed per-commit file diffs across the PR rather than counting its changed files. Leorio filed both under `ECON-8` and they are corrected here. Nothing read that version except the guard scan retired below: `scripts/surface_bootstrap.sh` and `hooks/session-start.sh` match the marker's **surface name** and stop before the version, and a mirror's correctness has always been `nen surface mirror check`'s byte comparison, which the stamp could only make stricter in the wrong direction — a skill whose body had not moved for fifty versions was byte-identical to a fresh generation but for its marker, and the check called that copy stale.
- **A third marker reader, and the one that was weakest.** `scripts/permissions_pack.sh`'s `ours_generated` was a single unterminated extended regex, `(surface: $2`, whose true return is what permits an OVERWRITE of an untracked file in a consumer's workspace — so a file marked `(surface: codex-experimental)` satisfied a `codex` query. It is now the same two fixed-string reads as the others, terminated at `)` or `,`, so no value reaches a pattern (Feitan, CWE-625). `scripts/surface_bootstrap_fixture_check.sh`'s markers move to the current grammar, which mutation-proved the four new ownership branches: replacing their literal with `XXBROKENXX` left the fixture green before and fails it now (Nobunaga). One marker there deliberately keeps the legacy form, as the row proving a pre-change copy is still read as its own surface's on the path that authorises an unattended install.
- **Both marker grammars are read, so a copy placed before this change still works.** A mirror placed into a consumer's workspace carries `(surface: <s>, stamp: <version>)` until its next refresh. `hooks/session-start.sh` cuts the surface name at whichever of `,` or `)` comes first and matches both forms as fixed strings (never a regex, so `$surface` never reaches a pattern); `scripts/surface_bootstrap.sh`'s `is_ours_hooks`, `has_marker_under` and `is_ours_codex_only` each accept both. `scripts/nen_global_fixture_check.sh` case 31b is the proof: a copy carrying the pre-#530 stamped marker still resolves its surface and still refreshes. A reader that stopped accepting the old form would stop refreshing those copies silently, which is the one failure this mechanism exists to prevent.
- **`docs/using/mirrors.md` § 1 reverses its own rule.** "A stamp behind `.claude-plugin/plugin.json` is drift even when the bytes match" is gone; a mirror whose bytes match a fresh generation is current, whatever the manifest beside it declares. `docs/surfaces/README.md`, `codex.md`, `cursor.md` and `antigravity.md` carry the new marker, `great-hiker` § 4 names `--manifest` in `--stamp`'s place, and `bakuryuha`, `getsuga`, `tenkai` and Phinks's brief drop their stamp references.

### Removed

- **`surfaces_stamp_scan` from `scripts/plugin_bump_check.sh`.** It existed only to name the bump as the cause of the drift the bump itself created (zheref/hatsu#99, which deliberately took no position on decoupling and routed it to a separate issue — this one, which also corrects that routing: `--stamp` is optional in the pinned generator, so no companion change was needed in it). With the stamp gone there is no lag to explain, and with the scan gone so is its whole attack surface: the PR-head-controlled marker text it had to sanitise against a forged workflow command, a CR, a malformed version and a symlinked surface directory. The guard's Codex-overlay read is untouched — `.codex-plugin/plugin.json`'s version is a real cache key and still must track the Claude manifest's. `scripts/plugin_bump_check_fixture.sh` replaces the eleven stamp-lag rows: the exact tree that used to fail by name now passes, a bumped manifest beside mirrors carrying no version passes, and each of those two is followed by a negative grep asserting the retired scan says nothing at all. A `head_token` sanitiser takes the deleted function's rule — anything outside `[0-9A-Za-z.+/_-]`, empty or over 128 characters becomes the fixed word `<malformed>` — and now covers the three head reads that SURVIVED and had never had it: the overlay's name and version, the no-bump refusal's head version (which fires on every refused PR), and the opt-out refusal's shipped-path list, where `PLUGIN_SURFACE_GLOBS`' own `*` admits a carriage return in a path. Four fixture rows prove no CR and no ESC reach the trusted job's log and that an ordinary value passes through unchanged (Feitan). The guard's pass line no longer claims the Codex overlay "consistent" where the head tree carries none, and says that a bump rewrites `surfaces/antigravity/plugin.json` rather than nothing at all (Nobunaga). `scripts/surface_mirror_regenerate_fixture.sh` § 6 runs the real pinned generator on a scratch checkout and asserts the count: a manifest-only version change rewrites exactly 1 mirror file, `surfaces/antigravity/plugin.json`, version line only, and no generated file carries a `stamp:` marker.
