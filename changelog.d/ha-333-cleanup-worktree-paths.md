### Fixed

- **`cleanup` admits a worktree path as a path, never as a Git branch name** ([#333](https://github.com/zheref/hatsu/issues/333)). § 4 put every name taken from the repository, worktree paths included, through `git check-ref-format --branch`, which refuses every native absolute path, so a clean merged worktree under `.nen/worktrees/` was always a named row and § 5's worktree removal was unreachable. Branches and remote heads keep the ref rule; a worktree path is now admitted by the new `scripts/cleanup_path_admit.ts` (TypeScript under BC-11, behind the forwarding shim `scripts/cleanup_path_admit.sh`), whose header is the rule: a canonical main-worktree core; a short trunk `--base` that exists (`refs/…`, `heads/main`, `@{-1}` refused); an absolute path in `^/[A-Za-z0-9._/-]+$` with no `.`/`..`/empty component or trailing slash; exactly `<core>/.nen/worktrees/<surface>/<name>` (kagutsuchi's fixed worktree kept); no symlink on the way; listed exactly in `git worktree list --porcelain -z`, read NUL-split so a newline in another path forges nothing; not prunable, holding no other worktree, not on the trunk. A refused path stays a named row with its reason and no command. An admitted one prints facts — `head`, `locked`, `kind` (`reviewer` for `hanten-*`/`prove-*`), `tree` and a `dirt` line per status entry, ignored entries and a status warning included, so an ignored `.nen/` ledger, an ignored `.env` or an unreadable directory never reads clean — and the one literal `git -C '<core>' worktree remove -- '<path>'`, printed and never run before the maintainer's pick, never `--force`. It prints no class: § 5's table, read from those facts and `nen wc classify`, is the only class owner, with a fall-through (no row matches → proposed) and the ledger rule alone for reviewer checkouts. Its `--self-test` runs as the new `cleanup-path-guard` lane and asserts every refusal's reason; Shizuku cites the rule; the evidence lives in `docs/ab/cleanup.md`. CONTRIBUTING's copy of the guarded scripts gains the four it was missing. Plugin bumped to 0.119.0 and the three surface mirrors restamped.
