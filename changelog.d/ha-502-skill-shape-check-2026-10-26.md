### Added

- **The skill shape, stated once and checked as touched (zheref/hatsu#502; SDD plan wave 4, assessment finding B6).** `docs/PROCESS.md` § *The skill shape* says every skill carries a Residue, an Authority and a Hard limits section. `contracts/skill-shape.json` holds the three heading requirements and a shrink-only, reasoned exemption list (empty); `docs/config/skill-shape.json.md` documents it. `scripts/skill_shape_check.mts` hands every touched `claude/skills/<name>/SKILL.md` to `nen pr body-check --requirements-from`, judged from the merge base. A touched skill missing a section fails by name, and an untouched one is never failed. An exemption with no reason, an unknown skill or section, a stale entry, or an entry added over the base's list fails by name. A heading that only mentions the word (`## 1. Invocation and authority`) is not the section. 25 of 60 skills lack at least one section today; each is fixed when an effort next edits it.
- **Coverage rows for decision rows and lanes (assessment finding C6).** Every `nen/decisions.json` row carries a sorted `citedBy` list: the skills whose `SKILL.md` cite its id as a code span. An ordinary-word id such as `merge` counts only beside a row context, so a stop-word or a git subcommand is not a citation. The seven rows no skill cites carry `uncitedReason`, and the `$comment`'s prose citation index is retired in favour of `citedBy`. `scripts/canon_coverage_check.mts` reports a wrong list by row id and reports by name any `project.lanes` key no canon file names. `docs/config/contract.json.md` § *Hatsu's own lanes* now names all 61 lanes, which closes the 19 no canon file named.
- **Lane `skill-shape-guard`**, run by `unit-tests.yml` through `scripts/unit_tests_ci.mts` once that runner is the base's. The runner hands every lane its own HEAD, the PR's base SHA, as `HATSU_BASE_SHA`. The live read judges from that commit's merge base and fetches and unshallows it in a shallow checkout. The live read is strict: a finding is exit 1, a read that could not run is `NOT CHECKED` at exit 2, and both fail the lane.
