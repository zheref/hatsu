### Added

- **A skill-shape check, enforced as touched (zheref/hatsu#502; SDD plan wave 4, assessment finding B6).** `contracts/skill-shape.json` states the shape canon asks for as data: a level-2 heading naming the skill's Residue, its Authority and its Hard limits, and a reasoned exemption list (empty). `scripts/skill_shape_check.mts` hands every touched `claude/skills/<name>/SKILL.md` (`--base <ref>`, `--base-root <dir>`, `--skills` or `--all`) to `nen pr body-check --requirements-from`, so the heading match is nen's: a touched skill missing a section fails by name, an untouched one is never failed, and an exemption with no reason, an unknown skill or section, or a stale section fails by name. 23 of 60 skills lack at least one section today; each is fixed when an effort next edits it.
- **Coverage rows for decision rows and lanes (assessment finding C6).** Every `nen/decisions.json` row carries `citedBy`, the skills whose `SKILL.md` cite its id as a code span, and the seven rows no skill cites carry `uncitedReason`, naming the `docs/WORKFLOW.md` or `docs/PROCESS.md` section that raises them. `scripts/canon_coverage_check.mts` reports, by row id, a missing, incomplete or over-long citing list, an uncited row with no reason and a stale reason, and, by name, a `project.lanes` key no canon file names. `docs/config/contract.json.md` § *Hatsu's own lanes* names every lane with the scripts its verb runs, closing the 19 lanes no canon file named.
- **Lane `skill-shape-guard`**, run by `unit-tests.yml` through `scripts/unit_tests_ci.mts` once this runner is the base's. The runner now hands every lane its own base-revision tree as `HATSU_BASE_ROOT`, which the shape check reads as `--base-root`. The live reads are advisory until one tagged green release (HR-13): a finding is printed and the lane stays green, a wiring refusal fails it.
