### Fixed

- **The `decisions` PR section resolves for any run that took a decision, not only an idle one (zheref/hatsu#474).** `contracts/pr-sections.json`'s footer row `decisions` (*Decisions taken on your behalf*) now carries `"when": "decisions"`, a new run fact, where it carried `"when": "idle"`. An attended run that applied a default or a ruling (zheref/hatsu#474 AC-1; an idle run's are [HR-334](docs/ROSTER.md#hr-334)'s) no longer has to drop the section or carry a failing strict check. Any positive source includes the section: `scripts/pr_sections_resolve.sh --decisions`, `--idle` (an idle run always pre-answers its rows), or `--decisions-from <nen.run manifest>` whose `idleAnswers` is not empty. The manifest proves only the pre-answers a run was launched with, since nen never updates `idleAnswers` and it is null on an attended run, so a null or empty map adds nothing: beside `--decisions` or `--idle` the flag wins, and alone it refuses at exit 1 rather than reading as "no decision". A default taken mid-run or attended is `--decisions`, passed by the session that took it. Every other `--decisions-from` input refuses at exit 1, whatever else is passed: a non-object, a row id outside `[a-z0-9-]+`, a value other than `default`, `hold` or `refuse`, and a repeated flag. In every file the resolver loads, a missing or unreadable file is reported by path and errno code, and unparseable JSON by path, error class and position, never by an excerpt of its bytes. A run that took no decision resolves no `decisions` requirement, as before. On zheref/hatsu#467's body the strict sections check and `nen pr body-check` now agree; `scripts/pr_sections_fixture_check.ts` proves it on that body's heading skeleton (`scripts/fixtures/pr-sections/ha-467-headings.md`) through the shim for each source, proves the footer on all 24 cells with and without the fact, and proves each refusal. `claude/skills/shibari/SKILL.md`, `claude/skills/tensho/SKILL.md`, `docs/PR-SECTIONS.md`, the section's template comment and `nen/workflow.json`'s `pr.$sections` annotation say when to pass it.
