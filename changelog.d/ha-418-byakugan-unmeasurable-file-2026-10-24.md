### Added

- **`hatsu:byakugan` § 8 has an option for a touched file the lane cannot measure (zheref/hatsu#418).** Option **E** applies where the lane declares coverage but not for this file's target: it names the missing capability (the SDK, the lane or the target that is absent) with the line that shows it, reports the file as `not measurable here — <capability>` rather than a number, has the PR state it, and leads to a proposal at the declaration gate (G4 in a canon repository, G2 in a consumer one), never to a lowered ladder or an added exclusion. § 8 now keeps one cause per option, so snapshot-covered UI, generated code and a lane-bound target are no longer folded into one waiver. § 9 tells apart a lane that declares no coverage (the seat, exit `4`) from a lane that declares coverage but cannot reach this file's target, which reaches § 8's stop; § 2's band table gains the `not measurable here` row. No change to `coverage.minimum`, the bands or any nen verb.
