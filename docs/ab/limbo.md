## 2. What these runs settle for the skill

- **Check before generate, always** (rows 10, 13, 14): a marked-but-edited file would be *overwritten*
  by `generate` (its bytes differ), while an *unmarked* one refuses the whole run — so the
  `hand-edited` class is read off `check` and gated before `generate` is called at all.
- **The predecessor's mirror is the first-run case for every existing consumer** (rows 13–14): a
  `sync-canon`-generated `.claude/rules/` carries a marker nen does not know, reads `hand-edited`, and
  refuses `generate`. Limbo names it by its first line and offers the `git rm`-then-regenerate route
  on the same stop, never silently.
- **A repin without a regenerate is `stale` everywhere** (row 11), so `to <tag>` moves the pin and
  regenerates in one commit.
- **The surface set is the consumer's declaration** (rows 15–16); nen refuses to default it and so
  does limbo.
- **`--markdown-out` needs its parent** (row 18) — residue 5 in the skill.
- **Idempotent** (row 9): a second `check` after `generate` must read `drift: none`; anything else is
  a finding about the generator, not a file to touch.
